# ShowMe Web & App — Websites & Mobile Apps That Ship Fast

Landing page for ShowMe Web & App. Built with Next.js 16 + Tailwind CSS v4, deployed to Vercel.

## Tech Stack
- Next.js 15 (App Router, static export)
- TypeScript
- Tailwind CSS
- Vercel

## Brand Colors
| Token | Hex | Usage |
|-------|-----|-------|
| Primary amber | `#FFB800` | CTAs, highlights, badges |
| Background dark | `#121212` | Page background |
| Secondary teal | `#00CED1` | Accents, links |
